# sonara-site

The published website for [Sonara](https://sonara.andon.dev), a Mac app for designing studios and live setups.

Everything here except this file and `.github/` is **generated** and pushed from Sonara's build pipeline. The workflow in `.github/workflows/pages.yml` deploys `main` to GitHub Pages. Edits made here by hand will be overwritten on the next publish.
