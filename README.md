# sonara-site

The published website for [Sonara](https://sonara.andon.dev), and later its hosted equipment library.

Everything here except this file and `.github/` is **generated**: the private `andrew-waters/sonara` repo pushes its `site/` folder into `main` on every change, and the workflow in `.github/workflows/pages.yml` deploys `main` to GitHub Pages. Edits made here by hand will be overwritten on the next publish.

To change the site, change `site/` in the sonara repo.
